# style-forge — инструмент единого стиля

Чтобы игра не выглядела как «нейрослоп», все ассеты должны быть в одном стиле.
Секрет: **нейросеть рисует только субъект, а оболочку собирает код.**

```
┌─ ChatGPT рисует ─┐      ┌──── style-forge собирает (детерминированно) ────┐
│  кота, врага,    │  →   │  бумага • рамка • палитра • баннер • энергия •   │
│  предмет (PNG)   │      │  цена • название • описание игровым шрифтом      │
└──────────────────┘      └──────────────────────────────────────────────────┘
```

Оболочка одинаковая для всех карт → единство, которое ИИ не может испортить.

---

## Твой цикл (3 шага на карту)

1. **Промпт.** Запусти `python3 forge.py prompts`. Открой `prompts/ALL.md` — там готовый
   текст на каждую карту.
2. **ChatGPT.** Открой **один** чат и генери в нём все ассеты подряд (так стиль держится
   стабильнее). Вставляй промпт, проси **PNG с прозрачным фоном**. Скачай картинку.
3. **Сборка.** Положи файл в `inbox/<id>.png` (например `inbox/firework.png`) и запусти
   `python3 forge.py build`. Готовая карта появится в `output/<id>.png`.

Пока картинки нет — рисуется плейсхолдер, чтобы видеть будущую карту.

### Три правила, чтобы стиль реально сошёлся
- Один общий чат в ChatGPT на все ассеты — он помнит стиль.
- Проси рисовать **только персонажа/предмет**, по центру, на прозрачном фоне, без рамки и текста.
- Прикладывай один и тот же референс стиля (или пиши «в том же стиле, что раньше»).

## Команды

```bash
python3 forge.py prompts             # промпты для ChatGPT → prompts/
python3 forge.py build               # собрать все карты → output/
python3 forge.py build --card firework   # собрать одну карту
```

## Файлы

| Файл                | Что это                                                        |
|---------------------|----------------------------------------------------------------|
| `style.config.json` | **Style Bible** — палитра, промпт-суффикс, негатив, шрифты, цвета типов. Единый источник правды: правишь тут — меняется вся игра. |
| `catalog.json`      | Список карт: id, название, тип, стоимость, текст и описание арта. |
| `forge.py`          | Инструмент: генерация промптов + сборка карт.                    |
| `inbox/`            | Сюда кладёшь картинки из ChatGPT (`<id>.png`).                   |
| `output/`           | Готовые карты.                                                   |
| `prompts/`          | Сгенерированные промпты.                                         |

## Как добавить новую карту
Допиши объект в `catalog.json` (`type`: `attack` / `skill` / `power` / `item`),
запусти `prompts`, прогони через ChatGPT, положи в `inbox/`, запусти `build`.

## Куда это растёт (следующие стадии)
- **Стадия 1 — своя LoRA.** Когда наберётся 30–40 хороших ассетов, обучаем LoRA на них —
  и стиль «вшивается» в модель, промпты становятся короче, дрейф исчезает.
- **Стадия 2 — ControlNet + референс-лист персонажа** для одинаковой композиции карт и
  единого вида кота во всех сценах.
- **Интеграция с Godot.** `output/` + `catalog.json` — уже готовый набор для загрузки в игру.

## Тонкая настройка
- Слишком «пёстрые» картинки? Подними `grade.tone_amount` в `style.config.json`.
- Другая палитра/сеттинг? Поменяй `style_bible.palette`, `prompt_suffix` и цвета в `card` / `types`.
- Свой шрифт для заголовков (с кириллицей)? Положи `.ttf` в `assets/fonts/` и укажи в `fonts.title`.
