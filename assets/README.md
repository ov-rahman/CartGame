# Ассеты игры

Библиотека присланных ассетов. Хранится в GitHub — значит доступна навсегда
и в любой сессии. Машиночитаемый список — в `library.json`.

## Папки
- `backgrounds/` — фоны экранов
- `characters/` — персонажи
- `icons/` — иконки (для карт, фон убран)
- `cards/` — готовые/особые карты

## Содержимое

| Файл | Название | Тип |
|------|----------|-----|
| `backgrounds/secret_merchant.png` | Тайная торговка | фон |
| `icons/gold_arrow.png` | Золотая стрела | иконка |
| `icons/firework.png` | Фейерверк | иконка |

## Как добавлять
Кидай ассет в чат — я кладу файл в нужную папку, чищу фон если это иконка,
и дописываю в таблицу и в `library.json` (с русским названием).
